# CIK867773-COMMON_2009-06-08 (SPWRA, SunPower Class A)

## 1. Verdict

Not an ending on 2009-06-08. SunPower Class A (SPWRA) kept trading until the share-for-share reclassification of Class A and Class B into one Common Stock, effective 5 pm on 2011-11-16 (new ticker SPWR). That is a continuation (decision 9). The library's 2009-06-08 date is a continued-filings guess, and its `continuation=false`, `transfer` row is wrong on date and on continuation.

## 4. Why this confidence

Inferred.
- Exit kind: filing (8-K 2011-11-16 item 1.01/3.03/5.03: share-for-share reclassification).
- Successor: filing (8-A12B 2011-11-16 registers the single class of Common Stock on Nasdaq Global Select; the 8-K says Common Stock has the Class A rights). The ticker SPWR is from the library's own history and fails rows, not read from a filing.
- Last trade date: worked out. The 8-K states the effective time 5 pm EST on 2011-11-16, after the close, so 2011-11-16 was the last SPWRA session; the 25-NSE (effective 2011-11-16) is dated the same day. No exchange print was read.
- Payout rule: filing (the same 8-K: no consideration).
- Terms: filing (share-for-share; same rights).
Not backed: an exchange print or notice stating the last SPWRA session. A Nasdaq notice or MIDAS row for 2011-11-16 would make it verified.

## 5. What happened

- Stockholders approved on 2011-11-15 a Restated Certificate reclassifying Class A and Class B on a share-for-share basis into one Common Stock with Class A's rights; effective 5 pm EST 2011-11-16 ([SEC 8-K 2011-11-16](https://www.sec.gov/Archives/edgar/data/867773/000119312511314493/d255917d8k.htm)).
- New 8-A12B registers Common Stock on the Nasdaq Global Select Market ([SEC 8-A12B](https://www.sec.gov/Archives/edgar/data/867773/000119312511314479/d257110d8a12b.htm)).
- Nasdaq filed a 25-NSE for Class A and Class B on 2011-11-16, effective the same day ([SEC 25-NSE](https://www.sec.gov/Archives/edgar/data/867773/000135445711000248/xslF25X02/primary_doc.xml)).
- Fails rows under SPWRA (CUSIP 867652109) run from 2009 to 2011-11-30; no SPWRA rows after, so the line stopped with the reclassification (SEC fails data).
- Between 2009-03 and 2011-06 the issuer filed 8-Ks only on ordinary business (no Form 25, no 3.01), so nothing ended in June 2009.

## 6. Decision-tree bucket

Replaced one for one by a new line of the same holders and the same issuer (same rights, no cash): a continuation.

## 7. Why the library got it wrong

The finder found no Form 25 for the era (flags `no_form25`, `delist_date_approx`), so it fell back to the continued-filings rule (304) and used the last sighting (2009-06-08) as a guessed end. The 2011 25-NSE lists "Class A & Class B" and did not match the observed security, and no successor was linked. Cause tag: `continued_filings_guess`.

## 8. Fix and open checks

- Match the 2011-11-16 25-NSE (class text "Class A") to the SPWRA security, and publish a continuation to the SPWR common line with last trade 2011-11-16; extend the SPWRA ticker range to 2011-11-16 and add SPWR from 2011-11-17.
- Open: confirm the last SPWRA session from an exchange print; confirm the new CUSIP.
- Golden case: yes, a dual-class reclassification continuation, well sourced.

## 9. Verification

Each field the report calls wrong was re-checked against the filings and fails rows. All three are upheld; one caveat on last_trade_date.

- **last_trade_date: upheld (the date is worked out, not a print).** The 8-K of 2011-11-16 (0001193125-11-314493, [SEC 8-K](https://www.sec.gov/Archives/edgar/data/867773/000119312511314493/d255917d8k.htm)) says the Restated Certificate "became effective at 5 pm Eastern Standard Time (EST) on November 16, 2011", reclassifying Class A and Class B share for share into Common Stock. The 25-NSE (0001354457-11-000248) has filing and effectiveness date 20111116, and the 15-12B (0001193125-11-314483) covers Class A and Class B the same day. So Class A did not end in 2009: the fails tool shows 572 SPWRA rows (CUSIP 867652109) from 2009-01-02 to 2011-06-30 and 32 rows 2011-10-03 to 2011-11-30. Caveat: 2011-11-16 is the effective date, not an exchange print. Under decision 12 a published contract date needs a print, so the contract value may stay blank until one is read; the 2009 date is what is refuted. The "inferred" confidence is fair.
- **value_rule: upheld.** Item 1.01 of the 8-K describes a share-for-share reclassification into Common Stock with the same rights as Class A; the Fifth Supplemental Indenture converts the debentures into Common Stock "on the same terms and in the same amount". No cash is part of the exchange, so this is a continuation (decision 9), not a `transfer` ending.
- **ticker_history: upheld.** The library's SPWRA range ends 2009-06-08, but SPWRA fails rows under the same CUSIP run to 2011-11-30. The exact end of 2011-11-16 rests on the same effective-time reasoning; the SPWR successor ticker was not re-read from a filing.

Refuted: nothing. Uncertain: the last session day itself (no print read).
