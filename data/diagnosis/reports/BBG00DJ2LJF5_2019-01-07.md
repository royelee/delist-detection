# DVMT (Dell Technologies Class V), case BBG00DJ2LJF5_2019-01-07

## 1. Verdict

A real merger: on 2018-12-28 each Class V share was converted into the right to receive $120.00 cash (capped at $14 billion in total, so prorated) or 1.8066 Dell Class C shares. The library calls it a continuation into Class C (BBG00DW3SZS1) with no value; the last trade date is right but the kind, successor and payout are wrong.

## 4. Why this confidence

Verified.
- Exit kind: filing (8-K 2018-12-28: each Class V share converted into cash or Class C shares in a merger).
- Successor: filing (same 8-K: no line continues one for one; holders get cash or another class).
- Last trade date: filing (8-K items 3.01 and 8.01: Class V ceased trading before the open on 2018-12-28, so the last trade was 2018-12-27).
- Payout rule: filing (8-K item 8.01: cash or stock election).
- Terms: filing (8-K: $120.00, 1.8066, proration factor about 0.6414; the aggregate package is worked out from those).

## 5. What happened

- The Class V transaction closed 2018-12-28: each Class V share became $120.00 cash (aggregate cap $14 billion) or 1.8066 Class C shares ([SEC 8-K 2018-12-28](https://www.sec.gov/Archives/edgar/data/1571996/000119312518360943/d673794d8k.htm)).
- Dell paid $14 billion in cash and issued 149,387,617 Class C shares; 91.2% of Class V shares elected cash, so cash was prorated by about 0.6414 (same 8-K).
- Class V ceased trading on the NYSE before the open on 2018-12-28; Class C (DELL) began regular-way trading that day (same 8-K).
- NYSE filed Form 25-NSE on 2018-12-28 ([SEC 25-NSE](https://www.sec.gov/Archives/edgar/data/1571996/000087666118001378/xslF25X02/primary_doc.xml)); Dell filed Form 15-12B on 2019-01-07 ([SEC 15-12B](https://www.sec.gov/Archives/edgar/data/1571996/000119312519003794/d684210d1512b.htm)).

## 6. Decision-tree bucket

Replaced: the holder surrendered the old share for cash or another class of shares, with $14bn of cash paid in the exchange. Per the operator ruling (cash paid for the old shares makes it a merger), not a continuation.

## 7. Why the library got it wrong

The finder matched the Form 25-NSE but classed the ending through `continued_filings_rule` (CRSP 304, exchange_transfer, "successor by same issuer") because the issuer kept filing, then linked Class C as successor. The cash and election terms in the 8-K were never used. Cause tag: `wrong_exit_kind`.

## 8. Fix and open checks

- Classify as a merger with the cash_plus_stock election package above, no successor link, DELL as the price security on 2018-12-28.
- The aggregate package is worked out from the 8-K's proration factor; a single elector's package differs (a cash elector gets 0.6414 x 120 cash plus the rest in stock).
- Golden case: yes, an election deal inside one issuer that a same-issuer rule reads as a continuation.

## 9. Verification

Re-read the 8-K of 2018-12-28 ([SEC 8-K](https://www.sec.gov/Archives/edgar/data/1571996/000119312518360943/d673794d8k.htm), accession 0001193125-18-360943) through `sec.py grep`.

- **exit_kind (merger, not exchange): upheld.** The 8-K says each Class V share "was converted into the right ... to receive either (1) $120.00 in cash, without interest, subject to a cap of $14 billion ... or (2) 1.8066 shares of Class C", under a merger agreement (Teton Merger Sub). Dell "paid $14 billion in cash and issued 149,387,617 shares" of Class C. Cash is paid as part of the exchange for the old shares, so reference.md's operator ruling makes it a merger, not a continuation. The ratio is also not 1:1 and it is not a holdco reorganization.
- **successor (none): upheld.** Class C (DELL) trades separately and is only the stock leg of the election; holders who took cash hold no successor line. Class C already traded (when-issued from 2018-12-26, regular-way 2018-12-28), so it is not a new line replacing Class V one for one.
- **value_rule (cash_plus_stock): upheld.** The 8-K gives the election and proration: 181,897,352 of 199,356,591 shares (91.2%) elected cash, about $21.8bn against the $14bn cap, proration factor about 0.6414. A holder therefore receives both cash and Class C shares.
- **Dates (not in dispute, checked in passing).** Class V "ceased trading prior to the opening of trading on December 28, 2018", so the last trade is 2018-12-27.

Caveat on the `terms` figures (the report marks `terms` as missing, which stands). Section 3's `cash_per_share 76.97` and `stock_ratio 0.6479` are the package of an electing holder (0.6414 x 120; (1 - 0.6414) x 1.8066), not the "aggregate package" that section 2 and the record call it. Over all Class V shares the aggregate is about $70.23 cash ($14bn / 199,356,591) and about 0.7493 Class C per share (149,387,617 / 199,356,591). Which package to publish for an election deal is a modelling choice; the open check in section 8 already says a single elector's package differs. This does not affect the three fields checked above.
