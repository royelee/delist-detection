# PARA (Paramount Global Class B), 2025: Skydance merger

## 1. Verdict

A real merger that closed 2025-08-07: each PARA Class B share became, at the holder's election, $15.00 cash (prorated) or one share of New Paramount (Paramount Skydance, PSKY, new CUSIP); non-electing holders got the one PSKY share. The library's kind and date are right, but its terms ($23.00 + 1.5333 shares) are the Class A consideration, not Class B's.

## 4. Why this confidence

Inferred.
- Exit kind: filing (8-K 2025-08-07, items 2.01/3.01/5.01).
- Successor: filing (same 8-K: New Paramount Class B shares issued; PSKY has CUSIP 69932A204, PARA 92556H206).

- Not backed: the PSKY first-trade date (assumed 2025-08-07 from the closing; fails rows show PSKY from 2025-08-08). A filing or exchange note stating it would make this `verified`.

## 5. What happened

- Closing 2025-08-07; Class B holders could elect $15.00 cash, subject to proration, otherwise got one New Paramount Class B share ([SEC 8-K 2025-08-07](https://www.sec.gov/Archives/edgar/data/813828/000119312525175027/d52142d8k.htm)).
- Class A holders (a different security, PARAA) got $23.00 cash or 1.5333 New Paramount Class B shares (same 8-K); the library took these terms for PARA.
- Proration: 285,889,212 Class B shares were paid cash ($4,288,338,180 aggregate); 318,818,445 New Paramount Class B shares were issued as stock consideration (same 8-K).
- Nasdaq filed Form 25-NSE for Class A and Class B, effective 2025-08-07 ([SEC 25-NSE](https://www.sec.gov/Archives/edgar/data/813828/000135445725000781/xslF25X02/primary_doc.xml)).
- Fails rows: PARA CUSIP 92556H206 last row 2025-08-18; PSKY CUSIP 69932A204 from 2025-08-08 (SEC fails data).

## 6. Decision-tree bucket

Replaced: old shares were exchanged for cash and/or shares of a new issuer line with a new CUSIP. Cash paid in the exchange makes it a merger, not a continuation.

## 9. Verification

Skeptic re-read the 8-K of 2025-08-07 ([SEC 8-K](https://www.sec.gov/Archives/edgar/data/813828/000119312525175027/d52142d8k.htm), accession 0001193125-25-175027) through sec.py grep, and the fails rows for PSKY.

- **terms: upheld.** The 8-K gives two separate consideration sets. Class A ($23.00 cash, "Class A Cash Consideration"; 1.5333 New Paramount Class B shares, "Class A Stock Consideration") applies to Class A shares (PARAA). Class B shares got $15.00 cash, subject to proration ("Class B Cash Consideration"), or otherwise "one (1) New Paramount Class B Share" ("Class B Stock Consideration"). The library's security is PARAB (`security_name` PARAMOUNT GLOBAL CLASS B, `share_class` CLASS B), so 23.00 + 1.5333 is the wrong class. The proration figure (285,889,212 Class B shares paid cash) is in the same 8-K. Fails rows show PSKY (CUSIP 69932A204) from 2025-08-08 (first $11.74), so the price_date of 2025-08-07 remains an assumption, already listed as an open check.
- **value_rule: upheld, with a convention caveat.** The Class B payout has no fixed cash+stock mix: it is cash $15.00 (prorated) or one PSKY share, so `cash_plus_stock` is not what the filing says. `stock` for the default package follows reference.md ("give the default or aggregate package the agreement fixes and say so"). The other reading, `cash` at $15.00, applies only to electing holders who were not prorated back; the report notes it as an alternative. How to value a prorated election deal is a convention the operator may still choose.
- Not checked (not called wrong by the report): exit_kind, last_trade_date, issuer, ticker_history.
