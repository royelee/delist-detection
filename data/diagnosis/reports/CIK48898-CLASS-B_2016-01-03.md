# CIK48898-CLASS-B_2016-01-03 (HUB-B, Hubbell Class B)

## 1. Verdict

A continuation: on 2015-12-23 Hubbell reclassified its dual-class stock into one class, and each Class B share became one share of the new common stock (NYSE: HUBB) with no cash. The library's `exchange` kind and 2015-12-23 last trade are right, but it names no successor and keeps the Class B line as an unresolved placeholder when the same line already exists in the run as BBG000BLK267.

## 5. What happened

- The reclassification of the dual-class stock into one class was completed 2015-12-23, effective 11:59 p.m.; each Class B share is reclassified into one share of Common Stock; Class A holders also receive $28.00 cash per Class A share ([SEC 8-K 2015-12-23](https://www.sec.gov/Archives/edgar/data/48898/000119312515412174/d110573d8k.htm)).
- NYSE trading in Class A and Class B was suspended and trading in the single class began 2015-12-24 under HUBB (same 8-K).
- The new common stock was registered under Section 12(b) on 8-A12B ([SEC 8-A12B 2015-12-23](https://www.sec.gov/Archives/edgar/data/48898/000119312515412157/d110579d8a12b.htm)).
- NYSE filed Form 25-NSE for Class B Common Stock, effective 2015-12-24 ([SEC 25-NSE](https://www.sec.gov/Archives/edgar/data/48898/000087666115000665/xslF25X02/primary_doc.xml)); a second 25-NSE (0000876661-15-000664) was filed the same day for the other class.
- Fails rows under HUBB: CUSIP 443510201 (Class B) 2015-11-02..2015-12-24, then CUSIP 443510607 from 2015-12-28 at similar prices (local `sec.py fails`).

## 6. Decision-tree bucket

Replaced 1:1 by a new line of the same holders: the Class B holder's claim is unchanged, one for one, no cash for Class B. The $28 cash was for Class A holders only. A continuation.

## 7. Why the library got it wrong

The finder labelled the ending through the continued-filings rule (`continued_filings_rule`, CRSP 304) and never linked a successor (flag `successor_unknown`). The Class B line was also resolved to a placeholder `CIK48898-CLASS-B` while `BBG000BLK267` (HUBB, 2008-01-29 onward, CUSIP 443510201 then 443510607) already is the same listed line, so the successor is in the run but unlinked. Cause tag: `other:class B reclassification 1:1 into new common, successor line BBG000BLK267 in the run but unlinked; Class B placeholder duplicates that FIGI line`.

## 9. Verification

Skeptic check of the two fields the report calls wrong (value_rule, ticker_history) and the continuation claim they rest on. Both upheld.

- **value_rule (transfer -> continuation): upheld.** 8-K item 3.03 ([SEC 8-K 2015-12-23](https://www.sec.gov/Archives/edgar/data/48898/000119312515412174/d110573d8k.htm)): Class A holders are entitled to $28.00 cash per Class A share, and each Class A share and each Class B share outstanding at the Effective Time (11:59 p.m. 2015-12-23) "shall be reclassified into one share of common stock". The cash is stated for Class A only. Class B gets one common share per share and no cash, so by reference.md's "no cash in the exchange" test it is a 1:1 continuation, not a merger. `transfer` is the wrong label because the CUSIP changes (443510201 to 443510607) into a successor line. The value effect is the same (return 0), but the rule and missing successor are wrong.
- **ticker_history (placeholder HUB-B line ending 2015-12-23): upheld, with a nuance.** Fails rows (local `sec.py fails`): CUSIP 443510201 "HUBBELL INC CL-B" under HUBB 2015-11-02..2015-12-24, last price $100.16 (the library's own last close), then 4 rows under another symbol to 2016-01-05. Class A is a different CUSIP (443510102, HUBA). `output/cusip_history.csv` gives BBG000BLK267 CUSIP 443510201 for 2008-01-29..2015-12-27 and 443510607 from 2015-12-28, while the placeholder CIK48898-CLASS-B holds the same CUSIP 443510201 for 2008-01-29..2015-12-23. One CUSIP is held by two sec_ids, so the placeholder duplicates the FIGI line. Nuance: the report says Class B "traded as HUBB"; the exchange symbol was probably HUB.B, shown as HUBB in the fails feed, so the observed HUB-B spelling is not itself wrong. The error is the separate placeholder line with its own ending.
- **continuation / successor: upheld.** Same issuer (CIK 48898), same holders, one for one, no cash for Class B. Weakness as in section 4: the link of the placeholder to BBG000BLK267 rests on the shared CUSIP, not on an OpenFIGI answer or a filing naming the FIGI. Confidence stays `inferred`.
- Not refuted: last_trade_date 2015-12-23 (last Class B fails row, dated 12-24, is priced at the 12-23 close). Not re-checked: which of 25-NSE -664/-665 covers Class B.
