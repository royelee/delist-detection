# BBG0060B3M63 (CRC) — regression diagnosis, 5a round 1

## 1. Verdict

BBG0060B3M63 is the FIGI of the original California Resources common stock (the CRCQQ line), so a CRC range under it is a real security. But the new range `CRC:2016-06-01..2020-07-20` starts in the wrong place. The 1-for-10 reverse split on 2016-05-31 is not an ending, and the stock has traded under this FIGI since the 2014-12-02 listing. Neither the old run (no range here) nor the new one (a range starting at the split) is right. The deeper fault is identity: the observed 2014-2015 CRC era sits on BBG00Y04KP80, which is the post-bankruptcy stock (it was cancelled at emergence in Oct 2020), not the stock observed.

## 6. Decision-tree bucket

Reverse split: kept the same security, so no row. The 2020 NYSE removal ends the original stock: lost to bankruptcy and valued at its first OTC print. The post-2020 stock is a new security.

## 7. Why the library got it wrong

- Cause tag: `identity_wrong`. The 2014-2015 CRC observations resolved to BBG00Y04KP80, the post-emergence stock; the original stock is BBG0060B3M63.
- Knock-on: the CUSIP change at the reverse split read as the end of the line. The `continued_filings_guess` row (reason "Continued 10-K/Q filings >180d after delist (moved to OTC or spun off); successor by line follow", flags `no_form25;last_trade_date_unconfirmed;delist_date_approx`) ends BBG00Y04KP80 on 2016-06-01, and the line follow adds BBG0060B3M63 from that date.
- The sibling case BBG00Y04KP80_5a-r1 judged the old run (one open range) right; that misses that this FIGI is the post-bankruptcy stock, which did not exist before 2020-10-28. This report records the conflict. The old run is not right either, since it gives the original stock no ending.

## 8. Fix and open checks

- Resolve the 2014-2015 CRC era to BBG0060B3M63 (identity route: the era's CUSIPs 13057Q107/13057Q206 under symbol CRC and the original issuer name, not the current ticker map). Then BBG00Y04KP80 has no pre-2020 range and BBG0060B3M63 gets one range 2014-12-02..2020-07-16 with a bankruptcy ending (dropped, otc_print).
- A CUSIP change by reverse split must not be read as an ending (rule: 8-K 5.03 with a reverse split, same issuer, same ticker).
- Open: exchange print for the last NYSE session; whether the new CRC (BBG00Y04KP80) should be added as a separate security from 2020-10-28, as the caller observed it.
- Golden candidate: yes (well-sourced, two false-merge traps: reverse split plus post-bankruptcy ticker reuse).

## 9. Verification

Result: upheld (field security_history.ranges, right = neither).

- Re-opened 8-K 0001609253-20-000116 (cached text): "NYSE also indefinitely suspended trading ... on July 16, 2020" and OTC trading under CRCQQ from July 17, 2020. Supports an end at the 2020 NYSE suspension, not 2020-07-20 (the fails-row date) as the new run has.
- Cached OpenFIGI answers give composite BBG0060B3M63 (share class BBG0060B3M54) for the CRCQQ line, so this FIGI is the original stock. The new range starts 2016-06-01 (reverse split date), the old run had none; the right start is the 2014-12-02 listing. So neither run is right. A reverse split is not an ending.
- Caveat: the 8-K does not say whether July 16 had a session. The end 2020-07-16 may be 2020-07-15 under decision 12's "suspended on D" convention. The start and the "neither" verdict do not depend on this; the end date value is weak.
- No missed filing is claimed (regression mode), none needed.
