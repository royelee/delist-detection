# CIK314808-COMMON_2010-01-08_5a-r1 (ESV, Ensco International / Ensco plc) - mismatch mode

## 1. Verdict

The library is right on all three fields; the truth row conflated two 1:1 continuations. On 2009-12-23 Delaware common became Ensco plc ADSs (same NYSE symbol ESV, new CUSIP 29358Q109), and on 2012-05-22 the ADSs became Class A ordinary shares (CUSIP G3157S106). The run holds the Delaware share and the ADS as one `sec_id` (CIK314808-COMMON, ESV continuous 2008-01-10 .. 2012-05-21) and links it to the Class A line. That line's placeholder id CIK314808-CLASS-A was renamed BBG000BJ2VQ6 (`contract/id_changes.csv`), so the successor "mismatch" is a rename. The truth's last trade 2009-12-22 is the right date for the 2009 step only, not for the ending this `sec_id` has.

## 4. Why this confidence

Inferred.
- Exit kind: filing (8-K 2012-05-15, items 1.01/1.02/3.03/8.01: deposit agreement terminated, ADSs converted into Class A shares, listed as ESV).
- Successor: filing (same 8-K) plus the library's id change record.
- Last trade date: worked out (the 8-K says the shares are anticipated to list on 2012-05-22; ADS fails rows end 2012-05-21). No filing states the last ADS day.
- Payout rule: filing (one for one conversion, no cash).
- Terms: filing (same).
Missing for `verified`: a filing or exchange print stating the last ADS trading day (for example the 8-K dated 2012-05-23 or a NYSE notice).

- 2012-05-14/15: Ensco and Citibank terminated the ADS deposit agreement to convert ADSs into Class A ordinary shares, listed on the NYSE on 22 May 2012 as ESV ([SEC 8-K 2012-05-15](https://www.sec.gov/Archives/edgar/data/314808/000119312512233095/d352333d8k.htm)).

## 7. Why the library got it wrong

It did not. The library folds the ADS into the Delaware line's `sec_id`, so the Dec 2009 step is no ending and the ending is the 2012 conversion. Its blank contract date follows decision 12. Cause tag: `truth_or_judge_issue` (the truth row for CIK314808-COMMON, dated 2010-01-08, scores a 2009 date and a placeholder id against a `sec_id` that now spans the ADS era).

## 9. Verification

Skeptic result: partly upheld.

- successor_sec_id (library, BBG000BJ2VQ6): upheld. `contract/id_changes.csv` row 25 records CIK314808-CLASS-A -> BBG000BJ2VQ6 (CIK 314808, CLASS A; `securities.csv` figi_source handoff). The value is the same security under its FIGI, so the mismatch is a rename.
- last_trade_date (library, blank, missed_filing 0001193125-12-233095): refuted. The cited 8-K (cache/edgar/text/000119312512233095.txt, date of report 14 May 2012) only says the Class A shares are "anticipated" to list on 22 May 2012. It says nothing about the 2009 Form 25-NSE removal the truth row scores (delist 2010-01-08, last trade 2009-12-22), so it does not show the earlier report wrong on that event. The library's `delistings.csv` has no 2010-01-08 row at all: it folds the ADS into one sec_id and drops a real Form 25 removal, which is a library modelling choice, not proof that the truth is wrong. The report itself concedes the truth's 2009 date is right for the 2009 step.
- internal_last_trade_date (library, 2012-05-21): refuted as a "library right" verdict. 2012-05-21 is worked out for a different ending (ADS to Class A) from an anticipated listing date, not stated by any filing; the diagnosis says so. The truth's 2009-12-22 is not shown wrong by the cited accession, and the rule forbids taking a library value without a missed filing that refutes the truth for that same event.
