## 4. Why this confidence
Verified.
- Exit kind: filing, 8-K 2020-07-31 (0001140361-20-017178) closing of the reorganization; Form 25-NSE 0001354457-20-000370.
- Successor: filing, same 8-K (acquirer BEP/BEPC, no continuing line).
- Last trade date: filing, same 8-K Item 3.01 (ceased trading before the open on July 31, 2020).
- Payout rule: filing, same 8-K (shares or units only, no cash but fractional cash).
- Terms: filing, same 8-K: non-electing holders got Holdings Class B, exchanged for BEPC Exchangeable Shares; electing holders got Class C, exchanged for BEP Units; ratio 0.47625 per the earlier report.

## 5. What happened
- Holders of Public TERP Shares who did not elect BEP Units received Holdings Class B stock, which BEPC acquired for BEPC Exchangeable Shares; those who elected BEP Units received Class C, acquired by Acquisition Sub for BEP Units ([SEC 8-K 2020-07-31](https://www.sec.gov/Archives/edgar/data/1599947/000114036120017178/brhc10013911_8k.htm)).
- Earlier report (BBG006KY8KV2_2017-10-17) found the same 8-K and chose BEPC.

## 6. Decision-tree bucket
Replaced by another company's stock (merger).

## 7. Why the library got it wrong
`terms_source=llm_election_stock`: the LLM picked BEP, the elected alternative, instead of the default (non-election) BEPC. Cause: `terms_misread`.

## 8. Fix and open checks
- For an election deal, price the default package (BEPC). The ratio is the same for both, so only the price security differs.
- Open: BEPC's sec_id is not in the run. Golden case: already covered by the truth set.


## 9. Verification
Upheld. Re-opened the cached 8-K 0001140361-20-017178: holders who did not elect BEP Units received Holdings Class B (exchanged for BEPC Exchangeable Shares); electing holders received Class C (BEP Units). The Adjusted Exchange Ratio 0.47625 applies to either. So BEPC is the default package and the truth price_ticker stands; no missed filing is claimed.
