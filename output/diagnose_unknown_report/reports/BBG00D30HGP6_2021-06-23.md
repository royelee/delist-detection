- EDGAR lists former name Colony Capital, Inc. (changed 2018-06-21) and the registrant continues to file under CIK 1679688 (10-Q 2021-08-09, [SEC 10-Q](https://www.sec.gov/Archives/edgar/data/1679688/000167968821000085/dbrg-20210630.htm)).

- No Form 25 for the common stock appears in the filings list from 2021-05-15 to 2021-08-15.

## 9. Verification

Skeptic re-check of the three fields the report calls wrong. Result: all three upheld, with two small factual corrections that do not change the verdict.

- **exit_kind: upheld.** The 8-K filed 2021-06-23 (accession 0001679688-21-000065) is items 5.03 and 9.01 only. Its cover page lists "Class A Common Stock ... DBRG ... New York Stock Exchange", and the same CIK 1679688 files on, so the issuer and listing are the same ([8-K](https://www.sec.gov/Archives/edgar/data/1679688/000167968821000065/dbrg-20210621.htm)). The filings list for 2021-05-01 to 2021-09-30 has no 8-K item 2.01, 3.01, 1.03 or 5.01 and no Form 15. The only Form 25 is a 25-NSE filed 2021-08-16 (0000876661-21-001196). It covers only "7.50% Series G Cumulative Redeemable Perpetual Preferred Stock", removed under Rule 12d2-2(a)(1) because the class was called for redemption. It is a different security class from the Class A common stock, so it does not end this sec_id. Correction: the report's section 5 says no Form 25 from 2021-05-15 to 2021-08-15. The window stops one day before this filing, but the filing belongs to the preferred and the conclusion stands. The library's own rows say `no_form25`, `delist_date_approx`, `exchange_transfer` (304), a continued-filings guess, which matches `reference.md`: a rename on the same security is not an ending.
- **last_trade_date: upheld.** The library publishes it blank and the corrected value is also blank, so the "wrong" status only means the row should not exist as an ending. No ending means no last trade. The fails data shows trading did not stop: CLNY (CUSIP 19626G108) has rows through 2021-06-23 and DBRG (25401T108) rows from 2021-06-22 through 2021-08-27 (`sec.py fails`). Correction: the report's section 5 says the first DBRG price 6.87 equals the last CLNY row. The tool output is CLNY first $6.87 and last $8.50, and DBRG first $8.50 and last $6.77. The first DBRG price equals the last CLNY price (8.50), which is the continuity the report meant.
- **ticker_history: upheld.** The library holds CLNY 2018-06-27 to 2021-06-23 and then ends it. The 8-K names DBRG as the Class A common symbol, and fails rows show the DBRG line trading from 2021-06-22 on at the CLNY closing price. The holders kept the same shares, renamed, so the history should continue under DBRG. Caveat: the CUSIP changed (19626G108 to 25401T108) and the library's `cusip_history` ends 2021-06-23. A new CUSIP on a renamed registrant is not a new security, since nothing was exchanged for cash or a different claim, but `reference.md` states the same-CUSIP rule only. Whether OpenFIGI keeps composite BBG00D30HGP6 for DBRG was not checked here, as the report's open check says.
- Not refuted: `cause = rename_not_followed`, `confidence = verified`, `golden_worthy = true`.
