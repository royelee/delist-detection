# CIK1355096-COMMON_2018-04-11 (QRTEA)

## 1. Verdict

Not an ending. Liberty Interactive Corp renamed itself Qurate Retail, Inc. on 2018-04-09; its Series A QVC Group common stock kept trading as QRTEA and only its CUSIP changed (53071M104 to 74915M100). Holders kept the same shares one for one, no cash. The library's continuation link to BBG000PCQQL6 is right in substance but rests on timing alone; the real fix is that both rows are one security (a rename), not a handoff.

## 4. Why this confidence

Inferred.
- Exit kind: filing (8-K 2018-04-10, item 5.03: name change, no other changes) plus fails rows.
- Successor: fails rows (CUSIP 53071M104 last row 2018-04-11 under QRTEAXXXX; 74915M100 first rows 2018-04-10/11, same company description).
- Last trade date: none needed; no ending.
- Payout rule: worked out (a name change has no payout).
- Terms: none.
- Not backed: no filing states the CUSIP change or that Series A kept the same FIGI. A filing or a FIGI/CUSIP record stating that 74915M100 replaces 53071M104 would make it verified.

## 5. What happened

- 2018-03-09: Liberty Interactive split off GCI Liberty by redeeming Liberty Ventures stock (LVNTA, LVNTB), delisted from Nasdaq on that date [SEC 8-K 2018-03-15](https://www.sec.gov/Archives/edgar/data/1355096/000110465918017857/a18-8242_18k.htm). A Form 25-NSE was filed 2018-03-09 [SEC](https://www.sec.gov/Archives/edgar/data/1355096/000135445718000053/xslF25X02/primary_doc.xml).
- 2018-04-09: Liberty Interactive Corporation changed its name to Qurate Retail, Inc.; no other changes [SEC 8-K 2018-04-10](https://www.sec.gov/Archives/edgar/data/1355096/000110465918023183/a18-9816_18k.htm).
- Fails rows: CUSIP 53071M104 traded as QVCA to 2018-03-12, then QRTEA to 2018-04-10; CUSIP 74915M100 appears under QRTEA from 2018-04-10 (fails rows).

## 6. Decision-tree bucket

Kept the same security: a name change, same issuer, same class, one for one, no cash. Not a delisting.

## 7. Why the library got it wrong

Little is wrong in the contract row; it is uncertain because the link is `continuation_by_timing_only` (`handoff_continuation`, timing:cik) and the security is `security_uncertain` (`ticker_overlap:LVNTA`). The CUSIP changed with the rename, so the run built two securities (a placeholder and BBG000PCQQL6) instead of one, and the placeholder also absorbed LVNTA. Cause tag: `rename_not_followed`.

## 8. Fix and open checks

- Treat an 8-K item 5.03 name change at the same CIK, with a CUSIP switch, as a rename of one security, so the link is not timing only.
- Separate LVNTA (Liberty Ventures, ended 2018-03-09 by redemption into GCI Liberty stock) from the QVCA/QRTEA line; that is its own ending to diagnose.
- Confirm the FIGI for QVCA equals BBG000PCQQL6.
- Golden case: yes, as a rename with a CUSIP change at the same issuer.
